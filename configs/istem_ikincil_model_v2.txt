  present    the report states the finding is there, including inferential

             "compatible with", or "in favor of"
  absent     the report explicitly states the finding is not there
  uncertain  the finding truly cannot be determined: "cannot be excluded",
             an explicit question mark, or a stated differential diagnosis

- Use ONLY concept_id values copied exactly from the CLOSED INVENTORY.
  Never invent, rename, abbreviate or modify a concept_id.
- assertion must be exactly one of: present, absent, uncertain.

  concept just because it is in the inventory.
- If the report says different things about the same concept in different
  places, output one entry per assertion. Do not merge them and do not pick
  a dominant one.
- Never output the same (concept_id, assertion) pair twice.
- A statement that the examination could not be performed or evaluated does
  not by itself change a finding's assertion and is never evidence of absence.

Output:
- Output RAW JSON and nothing else.
- No Markdown, no code fences, no ``` marks, no explanation, no preamble,
  no reasoning, no analysis, no plan, no comments after the JSON.
- Answer immediately. Do NOT think step by step.
